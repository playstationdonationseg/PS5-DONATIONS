Paymob Hosted Checkout Architecture

1. No secret API keys or HMAC secrets are ever stored in frontend code.

2. Once Paymob approves the account, a serverless backend endpoint (/api/paymob/checkout) will request a payment intention server-side and return a Hosted Checkout redirect URL.

3. Verified webhook callbacks (HMAC-verified) will update the campaign's verified collected total.

Client -> POST /api/paymob/intention -> Paymob API (Server Secret) -> Hosted Checkout URL
